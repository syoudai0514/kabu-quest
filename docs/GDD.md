## 1. タイトル案（3案）

| 案 | タイトル | 意図 |
|---|---|---|
| A（推奨） | **カブクエスト 〜タイムマシンとおかねのぼうけん〜** | 「クエスト＝冒険」のフレームが本作のストーリー構造（時代への旅→帰還→報告）と完全に一致する。略称「カブクエ」が子どもの口に乗りやすい。サブタイトルで内容が一発で伝わる |
| B | **ころがせ！おかねのゆきだるま** | 複利＝雪だるまという本作最大のビジュアルメタファーを前面に。5歳児にも「何をするゲームか」が直感的に伝わる。ただし「タイムマシン」要素が伝わらない |
| C | **フクじいのタイムマシンそうば** | キャラクター主導のタイトル。シリーズ展開（フクじいの◯◯）がしやすいが、初見のフックが弱い |

**推奨は A。** 理由: ①検索性と商標的な独自性、②「クエスト」がメタ進行（森を育てる・図鑑を埋める）と噛み合う、③おとなモードでも恥ずかしくないトーン。本ドキュメント内では「カブクエスト」で統一する。

## 2. コンセプトステートメント

> **「きみは、むかしの せかいに とばされた。いつの じだいかは、ひみつ。」**
>
> プレイヤーは時代を知らされずに過去の実在相場に降り立ち、1ターン＝1ヶ月で投資の旅をする。旅の終わりに「きみが いたのは、リーマンショックの ふゆ だったんだ」と時代が明かされ、歴史が物語として立ち上がる。暴落でパニックの誘惑に耐え、雪だるま（資産）を転がして大きくし、現代に持ち帰ったどんぐりで自分の森を育てる。

**設計の一行原則: 「知識を教える」のではなく「体験を先に、名前は後に」。** 子どもはまずリーマンショックを*生き延び*、その後で名前を知る。

## 3. ターゲットと二層設計

| レイヤー | 対象 | 体験 |
|---|---|---|
| こどもモード（デフォルト） | 5〜9歳 | ひらがな中心・漢字は全てふりがな（`<ruby>`）。用語は全て「さくせん語」に翻訳（§9）。数字は丸めて表示 |
| おとなモード | 親・高学年 | 実際の指数名・実年月・正確な数値・専門用語を表示。同じゲーム状態を別レンズで見る（データは共通、表示層のみ切替） |
| 親ダッシュボード | 親のみ（簡易ゲートで保護） | 子の選択ログから性格分析＋「今夜の会話カード」を生成（§12） |

**二層設計の要:** モード切替は「翻訳の切替」であって「難易度の切替」ではない。ゲームバランス・データは完全に共通。親が隣で「おとなモード」の画面を思い浮かべながら子の画面を見られる。

## 4. 世界観・ストーリー・キャラクター

### 世界観

「**どんぐりの森**」に住む子リスのコリンと出会ったプレイヤーは、森のはずれに住む発明家フクロウ「フクじい」のタイムマシンで、過去の「そうばの せかい」へ旅をする。旅で育てた雪だるまは、現代に帰るとどんぐりに変わり、森に木を植えられる。**森が育つ＝学びの記録**であり、メタレベルでも「時間をかけて育てる」を体験させる。

### キャラクター

| キャラ | 役割 | デザイン意図 |
|---|---|---|
| **コリン**（子リス） | 相棒。プレイヤーと一緒に旅をし、喜怒哀楽を代弁する。どんぐりを埋めて木を育てるのが夢 | リスの貯食行動は「今使わず、埋めて、育てる」という投資の完璧な生物学的メタファー。子どもの感情の受け皿（暴落時に一緒に不安がる→一緒に耐える） |
| **フクじい**（老フクロウ） | タイムマシンの発明家。出発時の案内と、帰還時の「じだいのタネあかし」を語る歴史の証人 | 知恵の象徴。教訓を「説教」でなく「昔話」として語る唯一のキャラ。「わしは あの ふゆを みておった…」 |
| **パニックン**（もやもやオバケ） | 敵役。暴落時に画面に現れ「うっちゃえ！ぜんぶ うっちゃえ！」と耳元でささやく | **本作の発明ポイント。** 狼狽（ろうばい）という*感情*をキャラとして外在化する。子どもは「自分の恐怖と戦う」のではなく「パニックンの誘惑に勝つ」。我慢に勝つたびパニックンは小さくなり、負けると太る。感情コントロールをボスバトルに変換する |

### ストーリーアーク（メタ進行）

1. **序章:** コリンの森は冬で食べものがない。フクじい「むかしの せかいには、おかねを そだてる ちえが ねむっておる」
2. **旅を重ねる:** 1回の旅＝1時代の追体験。帰還のたびに図鑑（じだいずかん・ことばずかん）が埋まり、森に木が増える
3. **中間ボス的節目:** 「ながいたび」モード解放（§7）。10年を耐え抜くとコリンの木が「おおきなカシの木」に成長
4. **エンディング（＝卒業）:** 全時代の図鑑コンプリートでフクじいから「とうしかの あかし」授与。「もう タイムマシンは いらんの。きみには *じかん* という ほんものの タイムマシンが あるからの」— **ゲームの外（現実の長期投資）へ橋を架ける一言**で締める

### ターン構造（1ターン＝1ヶ月）

1. **月が進む演出**（カレンダーがめくれ、雪だるまが坂を転がる。約1秒）
2. **チャート更新**: 保有資産の増減を雪だるまのサイズ変化＋効果音で表現
3. **収入**: 毎月おこづかい +1,000円（つみたての導線。§6.2）
4. **アクション（任意）**: かう / うる / なにもしない。**「なにもしない」が最速で正当な選択肢**であることがUI上重要（長期保有の肯定）
5. イベント月ならカード表示（§6.4）、あらし月ならパニックンバトル（§6.3）

**テンポ設計:** 24ターンのうち約16ターンは「タップだけで3秒」で流れる。イベント月（約5回）とあらし月（0〜3回、時代による）だけ立ち止まる。**5〜9歳の集中力に合わせ、1旅=実測5〜8分**を目標。全ターンで意思決定を強制しない——「何もしないで待つ」時間の心地よさ自体が長期投資の教材。

## 6. メカニクス詳細

### 6.1 タイムマシン相場

- **データ:** S&P500・日経平均の月次終値（1985年1月〜直近）をJSON同梱。出典はStooq（無料・再配布可の月次ヒストリカル）を第一候補、S&P500長期はShillerデータで補完。JSONに `source` / `retrieved_at` フィールドを必ず持たせる
- **時代の選択:** 完全ランダムではなく**「シナリオ重み付き抽選」**。24ヶ月窓を「おだやか」「のぼり坂」「あらし（危機を含む）」の3タイプに事前分類し、`おだやか40% / のぼり坂30% / あらし30%` で抽選。理由: 純ランダムだと1985年以降のS&P500は上げ相場に偏り、「我慢メカニクス」が発動しない旅が多発するため。**（意図的なバイアス。§13に明記）**
- **秘匿:** プレイ中は年号を隠し、チャートは「たびの1ヶ月め〜」表記。ただしニュースカードで時代の**匂わせ**は出す（「まちに『ケータイでんわ』というものが ふえてきた…」）。帰還時のタネあかしのカタルシスを最大化する伏線設計
- **同一窓の再抽選防止:** 直近5旅の窓は除外。危機イベント（後述の8大イベント）は図鑑が埋まるまで優先的に出やすくする

### 6.2 売買システム

- 資産は初期3種:
  - **アメリカのかぶセット**（S&P500連動）
  - **にっぽんのかぶセット**（日経平均連動）
  - **ちょきんばこ**（現金。増えないが減らない）
- 売買単位は**1,000円チャンク**。スライダーではなく「＋1000えん」ボタン連打式（未就学児の運指に合わせる）
- 毎月のおこづかい1,000円は自動では投資されない。**「まいつき かってに かうよ？」（つみたてスイッチ）**を旅の途中で解放し、ONにするとドルコスト平均法を体験できる。スイッチONで手が空く快感→「こつこつは ラク」を体感させる
- 端数処理: 保有は円建て評価額のみ管理し、口数・単価は持たない（子ども向け簡略化。§13）

### 6.3 我慢メカニクス（パニックンバトル）

発動条件: **単月−8%超の下落、または旅開始からの最大ドローダウン−20%超え**（おとなモードでは実数値表示）。

演出フロー:
1. 画面が暗転し、雪だるまが崖を転げ落ちる。コリン「うわーん！ちいさくなっちゃう！」
2. パニックンが出現し、画面を揺らして「いま うらないと ゼロに なっちゃうぞ〜！」
3. **3択提示: 「うる」「がまんする」「かいます」**
   - 制限時間は**設けない**（現実の投資に締切はない。焦らせる演出はパニックン側のセリフだけで行い、UIは静かに待つ——ここは意図的な非対称）
4. 選択の結果は**その場では評価しない**。「がまんボーナス」は帰還時に後述の「もしもタイムライン」とセットで初めて明かされる（即時報酬にすると「がまん＝正解」の暗記になり、思考が消えるため）

報酬設計:
- 底値から旅の終わりまでに回復した場合、「がまんする」「かいます」を選んだプレイヤーに**がまんメダル**（どんぐりボーナス+50%）
- 「かいます」を選び、それが底値圏だった場合は追加で**ゆうきメダル**
- 「うる」を選んだ場合もペナルティなし。ただし帰還時に「もしも」が表示される（次項）

### 6.4 もしもタイムライン（本作のキラー機能）

帰還時、プレイヤーの実績グラフの上に**半透明の「もしもゆきだるま」**を重ねて表示する:

- パニックンに負けて売った場合 → 「もしも がまんして いたら…」の資産曲線
- 耐え抜いた場合 → 「もしも あのとき ぜんぶ うっていたら…」の曲線（自分の判断の価値を可視化）
- ちょきんばこだけだった場合 → 「もしも かぶを かっていたら…」

**タイムマシンという世界観だからこそ、反実仮想が説教にならず「もうひとつの時間線」として自然に見せられる。** 投資教育の核心（機会費用・狼狽売りのコスト）を、一切の説明文なしにグラフ2本で伝える。

### 6.5 複利の可視化（ゆきだるま）

- 資産総額 = 雪だるまの体積（直径は資産の立方根でスケール。線形だと後半の成長が画面に収まらず、複利の「加速」も伝わらないため）
- ターン経過で雪だるまが坂を転がるアニメ。**増えた月は雪がくっつく音、減った月は欠ける音**
- 「ながいたび」モード（§7）では、前半ののろのろ成長と後半の急拡大の対比が最大の演出。10年めにコリンが「まえは ぼくより ちいさかったのに！」
- おとなモードでは同じ画面に対数/線形切替の資産曲線を表示

### 6.6 歴史イベント（じだいのタネあかし）

帰還時にフクじいが紙芝居形式（3〜5枚、1枚1文）で語る。初期収録8イベント:

| 時代 | 子ども向けタイトル | 一枚目の語り（トーン見本） |
|---|---|---|
| 1987 ブラックマンデー | いちにちで まっさかさまの日 | 「たった いちにちで、せかいじゅうの かぶが がけから おちたのじゃ」 |
| 1989-92 日本バブル崩壊 | おまつりのあとの ながい冬 | 「にっぽんじゅうが『かぶも とちも ぜったい あがる』と おまつりさわぎ での…」 |
| 1997-98 アジア通貨危機 | となりの国の かぜが うつった年 | — |
| 2000-02 ITバブル崩壊 | インターネットの ゆめの おまつり | 「『インターネットの かいしゃなら なんでも あがる！』みんなが ゆめを みたのじゃ」 |
| 2008-09 リーマンショック | おおきな ぎんこうが ころんだ冬 | 「おおきな ぎんこうが ころんで、せかいの おかねが こおりついた」 |
| 2011 東日本大震災 | じしんと かぶの はなし | （災害描写は最小限に。市場の回復と支え合いに焦点。**要親レビュー項目**） |
| 2020 コロナショック | せかいじゅうが おうちにこもった春 | 「でも かぶは びっくりするほど はやく げんきに なったのじゃ。なぜだと おもう？」 |
| 2022 インフレとりあげ年 | おかねの ねだんが かわった年 | — |

各イベントは**「なにが おきたか」→「ひとびとは どうしたか」→「そのあと どうなったか」**の3幕構成を厳守。教訓の明文化はせず、最後は必ずフクじいの問いかけで終える（親子の会話への送りパス）。

### 6.7 実績・メタ進行

- **どんぐり:** 旅のスコア（最終資産＋メダル）から換算。森に木を植える唯一の通貨
- **メダル図鑑:** がまんメダル / ゆうきメダル / こつこつ賞（つみたてを最後まで継続）/ たまごわけ名人（分散スコア高）/ ふっかつ賞（−30%から復活）/ ぜんぶなくしても わらった賞（大損の旅を最後まで完走）
- **じだいずかん:** 体験した歴史イベントが埋まる。**コンプリートがゲームクリア条件**
- **きせかえ:** コリンの帽子・マフラー等（どんぐり消費。ゲーム有利効果なし——pay-to-win構造を最初から排除し、将来の広告/IAPを「見た目のみ」に限定する布石）

### 6.8 失敗の演出

- 資産がどれだけ減っても「ゲームオーバー」画面は存在しない。旅は必ず24ヶ月で完走する
- 大損で帰還した場合、フクじいは慰めず**祝う**:「よう もちかえった。しっぱいは もりで いちばん たかい たからものじゃ」→ 専用メダル＋図鑑に「しっぱいのきろく」ページが増える（失敗の収集要素化）
- 「もういちど おなじ じだいへ」ボタンで同一窓に再挑戦可（タイムマシンの世界観的正当化）

## 7. 経済バランス（初期数値。プレイテストで調整前提）

| パラメータ | 値 | 意図 |
|---|---|---|
| 初期資金 | 10,000円 | お年玉スケール。子どもの実感が湧く唯一の金額帯 |
| 毎月おこづかい | 1,000円 | 24ヶ月で+24,000円。元本比2.4倍の入金があるため「入金力」の効果も自然に体験される |
| 旅の長さ（つうじょう） | 24ヶ月 | 5〜8分セッション |
| 旅の長さ（ながいたび） | 120ヶ月 | 3旅クリアで解放。複利と長期の本丸。テンポ倍速＋イベント密度調整で10〜12分 |
| 売買単位 | 1,000円 | ボタン連打式 |
| パニックン発動 | 単月−8% or DD−20% | S&P500/日経の月次分布から、あらし窓で1〜3回発動する閾値 |
| がまんメダル | どんぐり+50% | 最終資産よりメダルの寄与を大きくし、「儲け＜行動」の報酬構造にする |
| ちょきんばこ金利 | 0% | 簡略化（§13）。「へらないが ふえない」の対比役 |

**スコア星評価:** ★は絶対額でなく「同じ旅をちょきんばこだけで過ごした場合」との比較で決める。相場が悪い時代に−10%で済んだら高評価になり得る——**「相場は選べない、行動は選べる」**をスコア設計自体で表現する。

| リスク | ゆれ（おおきく そだつかも、へるかも） | 「危険」と訳さない。リスク＝変動幅という正しい理解を最初から植える |
| 指数（インデックス） | かぶセット（たくさんの かいしゃの つめあわせ） | |

**ことばずかん**に全訳語を収録し、おとなモードの正式名称と対で表示（親が「本当の名前はね」と教えられる構造）。

## 10. 音・手触り（フェーズ3詳細設計、方針のみ先行定義）

- 雪の付着音（増）/ 氷の欠ける音（減）/ どんぐりのコロコロ音（報酬）の3音を**感情のアンカー**として最優先実装
- 全タップに120ms以内の視覚＋触覚（`navigator.vibrate`対応機のみ）フィードバック
- パニックン出現時の画面シェイクは**設定でOFF可**（感覚過敏の子への配慮）
- BGMは環境音ベース（森・風）。ループの主張を弱くし、親のストレスを下げる（リビングで鳴り続ける音である前提）

## 11. 親ダッシュボード

子の全選択をローカルにイベントログとして記録し、3指標＋会話カードを生成:

| 指標 | 算出（概要） | 見せ方 |
|---|---|---|
| がまん力 | パニックンバトルでの「がまん/かいます」選択率、下落月の売却頻度 | パニックンとの対戦成績表（「3勝1敗」） |
| リスクとのつきあい方 | 平均現金比率、下落後の行動パターン | 「慎重派↔冒険派」のスライダー表示。**優劣の色付けをしない** |
| たまごわけ意識 | 資産配分のHHI（ハーフィンダール指数）の旅平均 | たまごとかごのイラスト |

**会話カード（本ダッシュボードの主目的）:** 「今日、◯◯ちゃんはコロナショックの時代を旅して、パニックンに勝ちました。『どうして がまんできたの？』と聞いてみてください」のような、**その日の実プレイに基づく質問文**を1日1枚生成。分析よりも会話のきっかけ供給を主機能とする。

ゲート: 「17×3は？」レベルの暗算2問（COPPA的にも個人情報不要な年齢ゲートの慣行に準拠）。

## 12. 金融的な簡略化の明示（レビュー観点）

あなた（発注者）のレビュー用に、意図的な簡略化を列挙する:

1. **配当を無視**（価格指数を使用）。S&P500は配当込みと比べ年約2%過小。→ 対応案: Shillerのトータルリターン系列に差し替え可能なデータ層にする。**v1は価格指数で開始し、おとなモードの注記に明記**
2. **為替を無視。** S&P500を円建て換算せずポイント→円1:1で扱う。円建てS&P500は為替でボラが変わるが、v1では「アメリカのかぶセット」の教育的単純さを優先
3. **手数料・税・スプレッドなし**
4. **月次終値のみ・成行約定・流動性無限**
5. **インフレ未調整**（名目リターンのみ。「おかねのねだんが かわった年」イベントで概念だけ触れる）
6. **ちょきんばこ金利0%**（実際は時代により日本の定期預金は6%あった。1990年前後の窓では歪みが出る——ここは要相談: 時代連動の預金金利を入れるか）
7. **時代抽選の意図的バイアス**（あらし30%。実際の月次分布より危機遭遇率が高い）
8. **口数・単価の概念なし**（評価額のみ管理。平均取得単価の教育は将来の高学年向け拡張で）

## 13. 技術アーキテクチャ概要

```
src/
├─ domain/          # 純粋ロジック。Reactに依存しない。Vitest対象
│   ├─ market/      #   価格系列・窓抽選・リターン計算
│   ├─ portfolio/   #   売買・評価額・分散スコア(HHI)
│   ├─ events/      #   パニックン判定・歴史イベントマッチング
│   └─ scoring/     #   メダル判定・もしもタイムライン算出・星評価
├─ data/            # 指数JSON（source/retrieved_at付き）・イベント定義・翻訳表
│   └─ providers/   #   DataProviderインターフェース（同梱JSON実装→将来API差替）
├─ state/           # Zustandストア（run / meta / settings / parentLog に分割）
├─ ui/              # 画面・コンポーネント。domainを呼ぶだけ
│   └─ i18n/        #   こども/おとな二層テキスト辞書（将来の多言語化と同一機構）
└─ platform/        # 保存(localStorage+スキーマバージョン)・音・振動・PWA
```

- **テスト必須対象:** リターン計算、複利（雪だるまサイズ）、パニックン発動判定、もしもタイムライン、がまんメダル判定、HHI、窓抽選の分類
- **保存:** `localStorage`（スキーマにversionフィールド、マイグレーション関数必須）。個人情報ゼロ（名前入力すら求めない。コリンが「きみ」と呼ぶ）
- **PWA:** vite-plugin-pwa。全データ同梱なので完全オフライン動作
- **広告への布石:** 画面レイアウトに広告スロットを予約しない代わりに、「旅と旅の間」だけを将来の広告挿入点として遷移設計上マークしておく（プレイ中断広告は子ども向けとして論外のため）

## 15. 凡庸回避——この設計が「遊びたい」と言える理由（設計者の自己弁護）

1. **感情の敵をキャラ化した（パニックン）。** 金融教育アプリの99%は「知識」を教えるが、投資の失敗の主因は知識でなく感情。本作は感情との戦いをボスバトルというゲーム文法に翻訳した
2. **反実仮想をタイムマシンで正当化した（もしもタイムライン）。** 「もし売らなければ」は現実では見えないが、このゲームでは*世界観の力で*見える。説教ゼロで機会費用を教える
3. **「何もしない」を最速・最楽の操作にした。** ゲームは通常、操作を要求するが、本作は無操作の心地よさを設計する。長期投資の本質は「行動しない技術」だから
4. **スコアが市況でなく行動を評価する。** 悪い時代を引いても高評価が取れる。運と実力の分離という、大人でも混同する概念を星の付け方で伝える
